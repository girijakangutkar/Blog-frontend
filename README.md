# Blog Frontend

A responsive blog application built with React that enables users to create, format, and publish blog posts with rich text and images. The frontend integrates React Quill for a seamless writing experience and displays published content dynamically on the homepage.

## Features

- Rich text editor powered by React Quill
- Image upload and preview support
- Dynamic rendering of blog posts on the homepage
- Clean and responsive UI for desktop and mobile
- Modular component architecture for scalability

## Tech Stack

- React
- React Quill
- CSS
